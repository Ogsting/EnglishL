# 主题图片素材（你提供，我这边已经接好）

把图片放进去、把开关打开，界面上就会自动用上；**不需要改任何组件代码**。

## 一句话流程

```
1. 作图 → 2. 放进 public/themes/minecraft/（文件名必须一致）
      → 3. 把 src/config.ts 里 USE_THEME_IMAGES 改成 true
      → 4. 刷新
```

开关默认是 `false`（`src/config.ts` 最后一行），这样你还没放图时不会满屏 404 报错。

## 代码在哪（你问的“对应的代码位置”）

| 你要改的东西 | 文件 | 位置 |
|---|---|---|
| **图片清单 / 文件名 / 段位图标映射 / 装饰图坐标** | `src/themes/themes.ts` | `mcImages` 常量（约第 90 行） |
| **图片总开关** | `src/config.ts` | 最后一行 `USE_THEME_IMAGES` |
| **页面背景怎么用上** | `src/App.vue` | `screenStyle` 计算属性 + `<main :style="screenStyle">` |
| **装饰图怎么渲染** | `src/App.vue` | `<img v-for="(d, i) in decor" class="decor">` + `decorStyle()` |
| **窗口背景（单词本/错题本）** | `src/views/OwnView.vue` / `WrongView.vue` | `class="list panel-own"` / `class="list panel-wrong"` |
| **卡片底图** | `src/style.css` | `.face { background-image: var(--img-card-frame) }` |
| **导航底图** | `src/style.css` | `.tabbar { background-image: var(--img-nav-bg) }` |
| **段位牌底图** | `src/style.css` | `.badge { background-image: var(--img-rank-badge) }` |
| **段位图标（有图用图，没图用像素画）** | `src/components/RankBadge.vue` | `iconFor()` |

## 想加第四张装饰图 / 换个位置

在 `src/themes/themes.ts` 的 `decor` 数组里加一行：

```ts
decor: [
  { src: themeAsset('minecraft', 'decor/torch.png'), x: 4,  y: 16, w: 11, opacity: 0.9, z: 0 },
  { src: themeAsset('minecraft', 'decor/chest.png'), x: 78, y: 60, w: 18, rotate: -8 },
]
```

| 字段 | 含义 |
|---|---|
| `x` / `y` | 相对整个 App 的百分比坐标（左上角原点） |
| `w` | 宽度占屏幕的百分比（高度按比例） |
| `opacity` | 0–1 |
| `rotate` | 旋转角度 |
| `z` | 层级，默认 0（内容永远在上层，不会被挡住点击） |

## 换了主题想各用各的图

`plain`（极简）主题的 `images` 现在是空对象，按同样结构填就行，图片放 `public/themes/plain/`：

```ts
images: {
  homeBg: themeAsset('plain', 'home-bg.png'),
  decor: [{ src: themeAsset('plain', 'decor/leaf.png'), x: 80, y: 10, w: 14 }]
}
```

## 小提醒

1. 尺寸不用严格按上表，但**背景图建议 9:19.5**（手机比例），否则会被裁切。
2. 段位图标必须是**透明背景 PNG**，我用的是 `object-fit: contain`，四周留白会被保留。
3. 像素风素材请用**整数倍**尺寸（比如 128 是 8 的倍数），放大时更干净。
4. 放好图后如果没生效，先确认开关改成了 `true`，再强制刷新（Ctrl+F5）。
