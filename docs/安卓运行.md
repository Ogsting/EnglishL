# 在 Android Studio 里跑这个 App

## 先搞清楚一件事

这个项目本身是 **Vue + Vite 的网页 App（PWA）**，不是 Android 原生工程。
所以 **不能直接把 `D:\EnglishL` 丢进 Android Studio** —— 它看不懂 `package.json` 和 `.vue`。

要跑在 Android Studio / 模拟器里，有两条路：

| 路线 | 做法 | 适合 |
|---|---|---|
| **A. 套原生壳（已配好）** | Capacitor 把网页打进 WebView，生成一个真正的 Android 工程 | 想在模拟器/真机上当 App 用、后面出 APK |
| **B. 直接开浏览器** | 模拟器里用 Chrome 打开宿主机的网址 | 只想快速看效果，0 配置 |

## 路线 B：最快（10 秒验证）

模拟器里访问宿主机的地址要用 **10.0.2.2**（Android 模拟器的固定约定，指向你的电脑）：

```
http://10.0.2.2:5173      # 开发模式，改代码自动刷新
```

前提是宿主机开着 `npm run dev:lan`（监听 0.0.0.0）。

## 路线 A：Android Studio 里跑（已经配好了）

### 我已经做完的

1. 接入 **Capacitor 6**（`@capacitor/core` / `android` / `cli`），生成 `android/` 原生工程
2. 把 `compileSdk` 定在 **34**（你机器上已装）
3. Gradle 从 8.2.1 → **8.7**、AGP 8.2.1 → **8.4.2**（因为你机器只有 JDK 21，老版本 Gradle 不支持）
4. 写了 `android/local.properties` 指向 SDK：`C:/Users/ogsting/AppData/Local/Android/Sdk`
5. 原生壳里不再注册 Service Worker（避免拿到旧缓存）

### 你只需要三步

1. **Android Studio → Open → 选 `D:\EnglishL\android`**（⚠️ 不是 `D:\EnglishL`）
2. 等右下角 **Gradle Sync** 跑完（第一次会下 Gradle 8.7 + 依赖，慢，属于正常）
3. 顶部设备下拉选 **Small_Phone**（你已有的 AVD）→ 点绿色 ▶ **Run**

装好后模拟器里就是这个 App，桌面图标名 `EnglishL`。

### 改完网页代码后

网页部分改动不会自动同步进原生工程，需要重新拷贝：

```bash
npm run build
npx cap sync android
```

然后 Android Studio 里再点一次 ▶（或者菜单 **Run → Apply Changes**）。

### 顺手出个 APK

Android Studio：**Build → Build App Bundle(s) / APK(s) → Build APK(s)**
产物在 `android/app/build/outputs/apk/debug/app-debug.apk`

命令行等价：

```bash
cd android
.\gradlew.bat assembleDebug
```

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| `SDK location not found` | `android/local.properties` 里的 `sdk.dir` 路径不对，改成你的实际路径 |
| `Unsupported class file major version 65` | Gradle 版本低于 8.5 却在用 JDK 21；本项目已升到 8.7 |
| Gradle 下载卡住 | 换国内镜像：把 `gradle-wrapper.properties` 的 `distributionUrl` 改成腾讯云/阿里云镜像 |
| 打开后白屏 | 忘了 `npm run build && npx cap sync android`，`dist/` 是旧的或空的 |
| 中文乱码 | 模拟器语言设成中文，或确认 `android/app/src/main/res/values-zh/strings.xml` 存在（Capacitor 默认带） |
