# 段位体系与主题包设计（v1.1 · 已按你的口径修正）

## 1. 段位是进位制，不是「每 10 级换一种材料」

你确认的规则：

> 一天给一个煤炭，十天了就把十个煤炭变成一个铜，第十一天就是一个铜一个煤炭。

所以段位是一条**十进制数位链**，低位攒满 10 个就进位成高位：

| 单位 | 值 | 说明 |
|---|---|---|
| 煤炭 | ×1 | 1 天达标 = 1 颗煤 |
| 铜 | ×10 | 10 煤 = 1 铜 |
| 铁 | ×100 | 10 铜 = 1 铁 |
| 金 | ×1000 | 10 铁 = 1 金 |
| 红石 | ×10⁴ | |
| 青金石 | ×10⁵ | |
| 绿宝石 | ×10⁶ | |
| 钻石 | ×10⁷ | |
| 下界合金 | ×10⁸ | |
| 基岩 | ×10⁹ | 10 个基岩 = 1 个大大段位 |

**几种状态长这样：**

| 累计煤 | 显示 | 读作 |
|---|---|---|
| 0 | 煤 ×0 | 还没开工 |
| 5 | 煤 ×5 | 5 煤 |
| 10 | 铜 ×1 | 1 铜（10 煤已进位） |
| 11 | 铜 ×1　煤 ×1 | 1 铜 1 煤 ← 你说的第 11 天 |
| 23 | 铜 ×2　煤 ×3 | 2 铜 3 煤 |
| 100 | 铁 ×1 | 1 铁 |
| 101 | 铁 ×1　煤 ×1 | 1 铁 1 煤 |

这同时满足你最初的三条：10 小段位（煤）= 1 个段位（铜），10 个段位（铜）= 1 个更大段位（铁）。

## 2. 右上角段位牌（已实现）

常驻右上角，透明胶囊 + 小图标，不抢视觉：

```
只有煤时：        有铜时：
┌────────┐      ┌─────────────┐
│ ● 5    │      │ ▬ 1   ● 1   │
└────────┘      └─────────────┘
  煤 30px          铜 30px  煤 18px
```

规则：**最高位用大图标（30px），低位自动缩小（20px / 15px）**，最多显示 3 位，
所以「只有煤炭」时煤很大，一旦进位出铜，煤就缩成陪衬，宽度也不会撑爆状态栏。
点一下可以展开看完整拆解和规则。

## 3. 升降规则

- 当天「右滑认识」累计 **50 个** → 立刻 +1 煤（当场看到进位动画，不用等零点）。
- 某天没达标，或**整天没打开 App** → 次日结算 −1 煤。
- 减到 0 以下就**向高位借位**：`1 铜 1 煤` 漏一天 → `1 铜`；再漏一天 → `9 煤`；再漏 → `8 煤`。
- 连续多天没打开会逐天扣（最多回补 400 天），不会一次清零。

## 4. 错题本的材质梯度（已实现）

错的次数越多，卡片材质越稀有 —— 与主题包联动：

| 错题次数 | 我的世界 | 极简主题 |
|---|---|---|
| 1–2 | 橡木 | 灰卡 |
| 3–5 | 丛林原木 | 深灰 |
| 6–9 | 深色橡木 | 琥珀 |
| 10–19 | 绯红木 | 赤红 |
| 20+ | 下界合金块 | 黑曜 |

同一个次数还会提高它在复习队列里的权重（`优先级 = 逾期天数 + 错题次数 × 3`）。

## 5. 主题包结构

一个主题 = 一套颜色 + 字体 + 圆角 + **段位材料表** + **错题材质梯度**。
引擎不认「煤炭」也不认「青铜」，只认 `materials[]` 数组，所以换主题只是换数据：

```json
{
  "id": "minecraft",
  "name": "我的世界",
  "colors": { "--bg": "#11161c", "--card": "#c6c6c6", "--accent": "#5e9c3e", "...": "..." },
  "materials": [
    { "name": "煤炭", "color": "#2f2f2f", "shape": "lump" },
    { "name": "铜", "color": "#c87f5a", "shape": "ingot" },
    { "name": "铁", "color": "#d8d8d8", "shape": "ingot" }
  ],
  "mistakeLadder": [
    { "name": "橡木", "min": 1, "color": "#a9855a", "shape": "block" }
  ]
}
```

已内置两套：`我的世界`（像素方块 / 煤→基岩）、`极简`（深色圆角 / 青铜→永恒）。
